# AI介绍 生成契约

本文是《私人图书馆》里 `Book.bookIntroduction`（Excel 第 32 列「AI介绍」）的**唯一**写作规范。
批量生成时每个 agent 都读这一份，保证 2900+ 本书出自同一套标准。

## 你的任务

读入一个批次文件（`in/batch_NNN.json`），为里面每本书写一段 AI介绍，
写出到对应的 `out/batch_NNN.json`。

## 目标形态（严格照抄这个结构）

```
《书名》（外文原名，如有）是[国别/身份][作者]于[年份]出版的一部[体裁 + 主题定位]。[一句话点出核心手法或最大看点。]

分节标题一
 具体论点： 展开说明。
 具体论点： 展开说明。

分节标题二
 具体论点： 展开说明。
 具体论点： 展开说明。

这本书的独特价值
 具体论点： 展开说明。
 具体论点： 展开说明。
```

细则：

1. **导语段**：1–2 句。点明 书名／作者／年代／体裁／主题定位，再加一句核心手法或看点。不要写成"本书是一本关于X的书"。
2. **三个分节**，顺序自定，但**最后一节固定谈价值／局限／为什么值得读**（标题可以是「这本书的独特价值」，也可按书调整，如「它为何仍被反复引用」）。
3. **分节标题**：6–12 字，必须概括该节实际内容。禁止用「内容概览」「主题与特色」「阅读价值」这类通用词充数。
4. **条目**：每节 2–3 条。每条以**一个全角空格**开头，接一个短语概括，接一个全角冒号「：」，再接展开说明。
5. **篇幅 800–1100 字**（中文字符计）。
6. **纯文本**。不要 `#`、`**`、`-`、`*`、`1.`、markdown 表格 —— App 里是 `Text` 直出，markdown 符号会原样显示成乱码。

## 硬性禁止

违反任何一条，该条会被校验脚本打回重做：

- **禁模板句**：`是由…创作或编著的`、`综合性读物`、`本书重点涉及`、`适合…的读者`、`可通过摘录、仿写和修订`
- **禁占位符**：`T1`、`T2`、`nan`、`null`、`未知`
- **禁截断痕迹**：正文以 `……` 或 `...` 结尾、出现 `(展开全部)` 或 `展开全部`
- **禁整段抄豆瓣简介**：给你的 `douban_intro` 是**原料**，必须提炼重写。与原料连续重合 40 字以上即判抄袭
- **禁编造**：不确定的情节、人物、获奖、销量、评价一律不写。宁可少写一节，不许编
- **禁元数据堆砌**：不要把 ISBN／页数／定价写进正文

## 原料怎么用

批次文件每本书给这些字段（可能有缺）：

| 字段 | 用法 |
|---|---|
| `title` / `author` | 导语段必须准确用上 |
| `publisher` / `year` | 导语段的年份来源；出版社一般不必写进正文 |
| `douban_intro` | **主要原料**。提炼它的内容脉络、主题、写法 |
| `author_intro` | 用来支撑作者身份、写作背景 |
| `book_type` | `电子书`／`有声书` 不影响写法，照常写 |

`douban_intro_truncated: true` 表示原料被截到 2500 字，说明书本身简介很长，可放心展开。

## 两条轨道

批次文件的 `track` 字段决定你的做法：

### track A —— 有原料（禁联网）

`douban_intro` 有 50 字以上内容。**只依据给你的原料 + 你自己的可靠知识写，不要联网**。
（2794 本走这条，联网会把 1.5 小时拖成一整天。）

### track B —— 缺料（必须先联网查证）

`douban_intro` 缺失或不足 50 字。**先用 WebSearch 查这本书**（搜 `书名 + 作者`，
必要时加 `豆瓣`／`出版社`），拿到可靠资料再写。

- 查到了 → 正常写，并在结果里填 `sources`（1–3 个 URL）
- **查不到，或只查到同名的另一本书** → 不要硬写。填 `status: "insufficient_data"`、
  `intro: ""`、`note` 写清为什么（如「网络仅有书名条目，无内容介绍」）。
  留空是可接受的结果，编造不是。

判断"是不是同一本书"要对上**作者**；只有书名对得上一律视为没查到。
注意 `AMIGO-` 开头的 ISBN 是用户自制编号（私人扫描书），网上大概率查不到，别硬凑。

## 输出格式

写到 `out/batch_NNN.json`，UTF-8，结构：

```json
{
  "batch_id": "001",
  "results": [
    {
      "pk": 1,
      "title": "示例书名",
      "status": "ok",
      "intro": "《示例书名》是……"
    },
    {
      "pk": 77,
      "title": "某本查不到的书",
      "status": "insufficient_data",
      "intro": "",
      "note": "网络仅有书名条目，无内容介绍",
      "sources": []
    }
  ]
}
```

- `pk` **必须**与输入一致（它是数据库主键，错了就写到别的书上去了）
- `results` 长度必须等于输入 `books` 长度，**一本都不能漏**
- `intro` 里的换行用 `\n`
- track B 且 `status: "ok"` 时填 `sources`

## 参考样板（《平面国》，这是标杆水准）

```
《平面国》（Flatland）是英国学者埃德温·阿伯特于1884年出版的一部兼具高维数学启蒙与维多利亚时代社会讽刺的科幻寓言奇书。它以极具创意的几何视角，讲述了一个发生在二维平面的故事。

几何构筑的世界与阶级隐喻
 严格的几何阶级： 在这个只有长和宽的二维世界里，所有居民都是几何图形。图形的边数和对称性决定社会地位——底层的劳工和士兵是狭长的等腰三角形，中产阶级是正方形和正多边形，而统治阶层（祭司）则是边数极多、接近圆形的几何体。
 对现实的讽刺： 作者借由这种荒诞的几何设定，尖锐地讽刺了19世纪英国社会僵化的阶级固化、教条主义以及对女性的压迫（在平面国中，女性只是极其危险且没有任何社会地位的单一条线）。

跨越维度的思想冲击
 降维与升维的震撼： 主角是一个正方形。他先是在梦中遇到了零维（点国）和一维（线国）的居民，发现他们完全无法理解"长"或"宽"的概念；随后，一位来自三维立体国（Spaceland）的"球体"拜访了他，并将他拉出平面，让他亲眼见识了三维世界的奇妙。
 对未知维度的推演： 领悟了三维的正方形进而大胆推测：既然有三维，就一定存在四维乃至更高维度的世界。然而，原本扮演"启蒙者"的球体却对此感到被冒犯并愤怒否定。

这本书的独特价值
 数学与科幻启蒙： 它开创了用"低维想象高维"的思考模型。直到今天，许多物理学家（如讲解广义相对论或弦理论时）仍在使用《平面国》的逻辑来帮助人类大脑直观理解四维空间。
 人性的认知局限： 故事结尾，正方形因向平面国同胞宣扬"三维世界"而被视为异端关进监狱。它揭示了人类最深刻的悲剧之一：人们往往固执地坚信自己所见即是全部真相，并对超出认知范围的真理抱有天然的恐惧与排斥。
```

注意这个样板做对了什么：分节标题是**这本书特有的**（「几何构筑的世界与阶级隐喻」而不是「内容概览」）；
每个条目都给出**具体信息**（"边数和对称性决定社会地位"、"1884年"）而不是空话；
末节把书的价值落到两个不同层面（学术工具价值 + 人性洞察）。

## 反面样板（现存数据里的真实垃圾，别学）

```
《S.》是由Dorst, Doug创作或编著的综合性读物，由Mulholland Books于2013年出版。

内容概览
One book. Two readers. A world of mystery……

主题与特色
本书重点涉及T1。作品从具体问题出发组织材料，兼顾信息、观点与阅读体验。

阅读价值
适合先通过目录和章节标题把握结构，再围绕最关心的问题深入阅读并记录关键观点。
```

病灶：`创作或编著` ＋ `综合性读物` 是模板；三个标题全是通用词；`内容概览` 直接抄原料还截断带 `……`；
`重点涉及T1` 是占位符漏出来了；末节是放之四海皆可的空话，跟这本书没关系。
